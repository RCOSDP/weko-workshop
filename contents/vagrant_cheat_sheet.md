# Vagrant cheat sheet

## Start the virtual machine

```
vagrant up
```

To specify a machine name, do the following

```
vagrant up machine_name
```


## Stop the virtual machine

```
vagrant halt
```

## Suspend the virtual machine

```
vagrant suspend
```

## Resume a suspended virtual machine

```
vagrant resume
```

## Show the virtual machine status

```
vagrant status
```

## Show ssh-config for the virtual machine

```
vagrant ssh-config
```

## Delete the virtual machine

```
vagrant destroy
```
