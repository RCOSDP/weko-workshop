# Virtualbox

Install Virtualbox to prepare a Docker environment. 

Virtualbox is an open source software for building virtual machines. It makes it possible to build a Linux machine on Windows. Other option in Windows is Windows Subsystem for Linux (WSL). However, unless you are familiar with WSL, we recommend you to use virtualbox or other virtual machines to install Linux.

WEKO3 can be easily run using Docker. Here we will start by building a virtual machine to install Docker.

Although it is possible to use the Docker environment of the OS you are familiar with, the behavior of Docker may differ from one OS to another, so this workshop will start with the installation of a virtual machine to unify the environment.

Download the virtualbox installer from virtualbox.org. Go to [https://www.virtualbox.org/wiki/Downloads](https://www.virtualbox.org/wiki/Downloads) in your browser.
