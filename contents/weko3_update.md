# WEKO3 Update

The procedure for updating WEKO3 in Kubernates is as follows

- [Build the new WEKO3 container image](build_the_new_weko3_container_image.md)
- (if necessary) Update Elasticsearch indexes and reindex
- (if necessary) Update PostgreSQL tables 
- (if necessary) Update data of WEKO3
- (if necessary) Update WEKO3 configuration for updates
- [Deploy the new WEKO3 container image](deploy_the_new_weko3_container_image.md)
