# Designing repository site

## Define a main contents for site design

Log in to WEKO3 as "System Administrator" or "Repository Administrator".

Go to the Administration page from the menu.

Open the left menu in the order of "Web Design" and "Widget".

Click "Create" tab.

Select "Root Index" as the value of the Repository item and "Main contents" as the value of the Type item. Enter an appropriate Name and click the "Save" button.

Note: If you use the "Web Design" function, you must set up "Main contents".

## Define a header widget for site design

Log in to WEKO3 as "System Administrator" or "Repository Administrator".

Go to the Administration page from the menu.

Open the left menu in the order of "Web Design" and "Widget".

Click "Create" tab.

Select "Root Index" as the value of the Repository item and "Header" as the value of the Type item. Enter an appropriate Name and header contents, then click the "Save" button.

## Configure page layout

Log in to WEKO3 as "System Administrator" or "Repository Administrator".

Go to the Administration page from the menu.

Open the left menu in the order of "Web Design" and "Page Layout".

Select "Root Index" as the value of the Repository item and "Main layout" as the value of the pages. 

Add a Widget to the Page and save the layout with the Save button.
